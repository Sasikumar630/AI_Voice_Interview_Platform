# 🎤🤖 AI Voice Interview Preparation

An AI-powered voice interview preparation platform that helps students and job seekers practice mock interviews, receive AI-generated questions, and improve their interview performance.

## ✨ Features

* 🤖 AI-generated interview questions using Google Gemini AI
* 🎙️ Voice-based mock interviews
* 🧠 AI-powered answer evaluation and scoring
* 📊 Strengths, weaknesses, suggestions & ideal answers
* 🔐 Firebase Authentication
* ☁️ Firestore for storing interview results
* 📱 Responsive and mobile-friendly UI

## 🛠️ Tech Stack

* React.js
* JavaScript
* SCSS
* Google Gemini AI
* Firebase
* Firestore
* Web Speech API

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/AI-Voice-Interview-Preparation.git
cd AI-Voice-Interview-Preparation
npm install
npm run dev
```

Create a `.env` file and configure your API credentials:

```env
VITE_GEMINI_API_KEY=your_api_key
```

> ⚠️ Keep API keys and Firebase credentials secure. Do not commit sensitive `.env` files.
